## 🧠 Overview

Plex Earth is a geospatial software solution designed to bring satellite imagery, terrain information, and geographic data into CAD-based design workflows. It integrates with Autodesk AutoCAD and Civil 3D, helping engineers and designers work with real-world locations directly within their drawing environment.

The software provides tools for accessing and importing georeferenced imagery and geographic information. Users can bring aerial and satellite imagery into their CAD projects to support site planning, infrastructure design, land development, and other engineering tasks.

Plex Earth helps connect CAD drawings with real-world coordinate systems and geospatial sources. This allows project teams to use location-based information as context for design decisions, map-based analysis, and documentation.

Its workflow is intended to simplify the process of obtaining, positioning, and managing geographic data in CAD projects, reducing the need to switch repeatedly between separate mapping applications and design software.
